# OpenAAS

OpenAAS is a Python project for Asset Administration Shell (AAS) modeling, OPC UA interoperability, and AASX packaging.

## Packages

- `aasmodel`: Pydantic AAS metamodel classes compatible with `schemas/aas.json`.
- `opcuaserver`: Build and run OPC UA servers from AAS JSON payloads.
- `opcualoader`: Load OPC UA structures back into AAS JSON.
- `aasxpackage`: Create `.aasx` packages from JSON or model instances.
