# OPCUALoader

`opcualoader` connects to an OPC UA server generated by `opcuaserver`, scans its AAS tree, and exports a valid AAS Environment JSON.

## Features

- Connects to anonymous or username/password OPC UA endpoints.
- Reads the `Objects/AAS` tree and reconstructs:
  - `assetAdministrationShells`
  - `submodels`
  - `submodelElements`
- Converts writable variables to `category: "VARIABLE"`.
- Validates generated JSON against `schemas/aas.json`.

## CLI

```bash
opcualoader opc.tcp://0.0.0.0:4841/opcuaserver/server/ -o exported-aas.json
```

With authentication:

```bash
opcualoader opc.tcp://0.0.0.0:4841/opcuaserver/server/ --username admin --password secret -o exported-aas.json
```
