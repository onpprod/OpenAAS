# OPCUALoader

`opcualoader` connects to an OPC UA server created by `opcuaserver`, scans the `Objects/AAS` tree, rebuilds an AAS Environment JSON, and optionally validates it against `schemas/aas.json`.

## What It Does

- Connects to anonymous or username/password OPC UA endpoints.
- Reads the `Objects/AAS` node structure.
- Reconstructs:
  - `assetAdministrationShells`
  - `submodels`
  - `submodelElements`
- Reads explicit OPC UA `category` metadata nodes created by `opcuaserver`.
- Falls back to variable write access when explicit `category` metadata is absent.
- Maps OPC UA data types to AAS `valueType` (`xs:*`).
- Validates the generated JSON using `schemas/aas.json` (enabled by default).

## Requirements

- Python 3.13+
- Project dependencies installed (`pip install -e .` or equivalent)

## CLI Usage

Basic export to file:

```bash
opcualoader opc.tcp://0.0.0.0:4841/opcuaserver/server/ -o exported-aas.json
```

Print JSON to stdout:

```bash
opcualoader opc.tcp://0.0.0.0:4841/opcuaserver/server/
```

Authenticated endpoint:

```bash
opcualoader opc.tcp://0.0.0.0:4841/opcuaserver/server/ --username admin --password secret -o exported-aas.json
```

Compact output and skip schema validation:

```bash
opcualoader opc.tcp://0.0.0.0:4841/opcuaserver/server/ -o exported-aas.json --compact --no-validate
```

### CLI Options

- `endpoint` (positional): OPC UA endpoint URL (`opc.tcp://...`).
- `--output`, `-o`: output JSON path. If omitted, JSON is printed to stdout.
- `--schema`: schema file path used for validation. Default: `schemas/aas.json`.
- `--username`: username for authenticated endpoints.
- `--password`: password for authenticated endpoints.
- `--no-password-prompt`: disables interactive password prompt when `--username` is set without `--password`.
- `--timeout`: connection timeout (seconds). Default: `10.0`.
- `--compact`: writes compact JSON (no indentation).
- `--no-validate`: skips schema validation of generated JSON.

## Python API

### 1) Load JSON in memory

```python
import asyncio
from opcualoader import load_aas_environment_from_server

async def main() -> None:
    environment = await load_aas_environment_from_server(
        endpoint="opc.tcp://0.0.0.0:4841/opcuaserver/server/",
        username=None,
        password=None,
        timeout=10.0,
        schema_path="schemas/aas.json",
        validate_schema=True,
    )
    print(environment.keys())

asyncio.run(main())
```

Function:

- `load_aas_environment_from_server(endpoint, *, username=None, password=None, timeout=10.0, schema_path=None, validate_schema=True) -> dict[str, Any]`

### 2) Export directly to a file

```python
import asyncio
from opcualoader import export_aas_environment_to_file

async def main() -> None:
    environment = await export_aas_environment_to_file(
        endpoint="opc.tcp://0.0.0.0:4841/opcuaserver/server/",
        output_path="exported-aas.json",
        username=None,
        password=None,
        timeout=10.0,
        schema_path="schemas/aas.json",
        validate_schema=True,
        pretty=True,
    )
    print(len(environment.get("submodels", [])))

asyncio.run(main())
```

Function:

- `export_aas_environment_to_file(endpoint, output_path, *, username=None, password=None, timeout=10.0, schema_path=None, validate_schema=True, pretty=True) -> dict[str, Any]`

## Mapping Notes

- Variables become AAS `Property` elements.
- Explicit OPC UA metadata node `category` is used when present.
- If metadata is missing, variable write access controls AAS category:
  - writable -> `VARIABLE`
  - read-only -> `CONSTANT`
- Range nodes are mapped when children are `min`/`max`.
- Operation nodes are detected from `InputVariables`, `OutputVariables`, and `InOutputVariables` folders.
- Nested object structures are mapped to `SubmodelElementCollection`.

## Validation and Errors

When validation is enabled, generated JSON is checked against `schemas/aas.json`.

Main errors:

- `OPCUALoaderSchemaError`: generated JSON is not schema-compliant.
- `OPCUALoaderSpecError`: invalid endpoint, invalid structure, missing `Objects/AAS`, unsupported/malformed source.
- `FileNotFoundError`: schema path not found.

## Current Scope

- Designed for servers generated by `opcuaserver`.
- Focused on the `Objects/AAS` structure produced by this project.
- Does not attempt to infer full semantic metadata beyond what is available in the node tree.
